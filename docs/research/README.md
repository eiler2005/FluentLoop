General English is the foundation in every track. Workplace modules supplement
it. The current user-selected recommendation is **30% general / 40% work / 30%
lexical learning**, replacing the earlier two-part recommendations. These are
three disjoint buckets; lexical slots include new senses and spaced review.
Their contextual strand does not create a second allocation credit. This allocation is a product preference, not a CEFR
requirement, and remains editable. Industry sources supply authentic
task contexts, not language-level certification or claims about all employers.
